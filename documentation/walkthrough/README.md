# pt-plan walkthroughs

A set of short, feature-focused tours of **pt-plan**, the graphical
project-plan editor. Each walkthrough builds a small example plan and shows one
area of the program. The example data is intentionally whimsical (a Hobbit
theme): action names and role names are drawn from a word pool, so they do not
have to mean anything — they only make the features easy to see.

All screenshots were captured from the live application.

| # | Walkthrough | Shows |
|---|-------------|-------|
| 1 | [Getting started](01-getting-started.md) | Create a plan, set the window and unit, add actions, fit-to-window zoom |
| 2 | [Sections & colours](02-sections-and-colours.md) | Swimlanes, WBS numbering, per-section and per-action colours |
| 3 | [Roles & assignments](03-roles-and-assignments.md) | Project roles, percentage assignments, the role view |
| 4 | [Dependencies & milestones](04-dependencies-and-milestones.md) | Typed links (FS/SS/FF), milestones, violation warnings |
| 5 | [Details, notes & report](05-details-notes-and-report.md) | Drill-down detail planning, sticky notes, the PDF report |

## Cast

The example plans assign a **role** (a job) to each member of the company. The
role is what pt-plan tracks; the actor is just who plays the part.

| Role | Played by |
|------|-----------|
| Wizard | Gandalf |
| Burglar | Bilbo |
| King | Thorin |
| Counsellor | Balin |

> Roles carry a distinct colour and a percentage share of each action's effort.
